To use push notification-based authentication, you need to configure at least one push notification provider in {edition.productName}. WSO2 Identity Server supports **Firebase Cloud Messaging (FCM)** as a push notification provider.

## Configure the push provider

1. On the {edition.productName} Console, go to **Notification Channels** and select **Push Providers**.

      <img src={require("../../../assets/img/guides/mfa/push/push-providers-page.png").default} alt="Notification channels page" width="600" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

2. Select the tab for the provider you want to configure and follow the steps in the relevant section below.

### Configure Firebase Cloud Messaging (FCM)

1. Select the **Firebase** tab.

2. Upload the `service-account.json` file that you downloaded from Firebase when you created your Firebase project.

      <img src={require("../../../assets/img/guides/mfa/push/push-provider-configure-fcm.png").default} alt="Configure Firebase" width="600" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

3. Click **Update** to save your changes.

      <img src={require("../../../assets/img/guides/mfa/push/push-provider-configured-fcm.png").default} alt="Update Push Provider" width="600" style={{display: "block", margin: "0", border: "0.3px solid lightgrey"}} />

:::note
Firebase Cloud Messaging can send push notifications to iOS devices through Apple Push Notification Service (APNs). However, you need to configure APNs separately to send push notifications to iOS devices. For more information, [refer to the Firebase documentation](https://firebase.google.com/docs/cloud-messaging/ios/client).
:::
