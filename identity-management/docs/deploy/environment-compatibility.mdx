## Tested DBMSs

WSO2 Identity Server supports the following DBMSs:

- MySQL 8.0

    :::warning
    To use MySQL 8.0, you need to create the database with charset latin1 as shown below:

    ```text
    create database regdb
    character set latin1;
    ```
    :::

- MySQL 5.7
- Oracle 19C
- Oracle SE2-19.0
- Microsoft SQL Server 2022
- SQLServer-SE-14.00
- DB2 v11.5
- Postgres 10.19
- Postgres 13.7
- Postgres 14
- Postgres 16
- Postgres 17
- Embedded H2
