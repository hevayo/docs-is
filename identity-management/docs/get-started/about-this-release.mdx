### What is new in this release

**WSO2 Identity Server 5.9.0** is the **latest WSO2 Identity Server release** and is the successor of WSO2 Identity Server 5.8.0. It contains the following new features and enhancements:

- **Reusable script library for adaptive authentication**: WSO2 Identity Server already supports script-based adaptive authentication. This feature supports easily manageable function libraries that can be imported to the authentication scripts. For more information, see [Adaptive Authentication with Function Libraries](../learn/tutorials/adaptive-authentication/scenarios/adaptive-authentication-with-function-library.mdx).

- **New REST APIs**: This release includes new REST APIs for end users who can be authenticated to the system to manage their user account related activities.

  - [Manage challenge question answers](../develop/developer-guide/using-apis/rest-apis/challenge-rest-api.mdx)
  - [View Authorized OAuth applications and revoke authorization from applications](../develop/developer-guide/using-apis/rest-apis/authorized-apps-rest-api.mdx)
  - [Manage associated accounts](../develop/developer-guide/using-apis/rest-apis/association-rest-api.mdx)
  - [View and revoke login sessions](../develop/developer-guide/using-apis/rest-apis/session-mgt-rest-api.mdx)
  - [Manage pending approvals](../develop/developer-guide/using-apis/rest-apis/approvals-rest-api.mdx)
  - [Manage devices with FIDO2](../develop/developer-guide/using-apis/rest-apis/fido-rest-api.mdx)
  - [Manage TOTP URLs and secrets](../develop/developer-guide/using-apis/rest-apis/totp-rest-api.mdx)

- **New Configuration model**: Configuring WSO2 Identity Server is made easier with a simplified, centralized [configuration model](../references/new-configuration-model.mdx) that supports injecting configurations with numerous methods such as environment variables, to improve compatibility with various configuration automation tools and cloud native environments.

### What has changed in this release

#### Removed features and functionalities

- Logging Monitor UI

#### Deprecated features and functionalities

- Writing Password Policy validators 
- Access token partitioning
- Support for MySQL versions prior to 5.7
