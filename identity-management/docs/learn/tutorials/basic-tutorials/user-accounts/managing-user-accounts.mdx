A **user account** is the digital representation of a physical user who interacts with an application. It is an entity that comprises the private information such as the user name and password of a user. 

<img src={require("../../../../../assets/img/learn/user-account.png").default} alt="User Account" width="600" />    

WSO2 Identity Server enables the following user account management features:

-    [User Registration](./user-registration/user-registration.mdx)
-    [Password Policies](./password-policies/configuring-password-policies.mdx)
-    [Password Reset](./password-reset/configuring-password-reset.mdx)
-    [User Name Recovery](./configuring-user-name-recovery.mdx)
-    [Account Locking](./account-locking/configuring-account-locking.mdx) 
-    [Account Disabling](./configuring-account-disabling.mdx)

:::note
To learn about how to create users and roles, see [Adding Users and Roles](../adding-users-and-roles.mdx). 
:::
