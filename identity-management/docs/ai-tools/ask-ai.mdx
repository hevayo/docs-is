Ask AI is an AI assistant built into the {edition.productName} Console. Ask it questions in plain language to learn how to use {edition.productName}, look up resources in your organization, review your security settings, and prepare changes that you review and confirm before they take effect.

:::note
Ask AI can make mistakes. Always review its answers and proposals before you act on them.
:::

## What Ask AI can do

- **Get answers from the documentation** - Ask how to use any {edition.productName} feature, and Ask AI answers from the {edition.productName} documentation with step-by-step instructions for the Console. For example:

    - `How do I add MFA to my application?`
    - `What is the difference between organization roles and application roles?`
    - `How do I set up Google login?`

- **Management operations in the organization** - Look up resources, create new ones, review security settings, and map user store attributes in your organization. Ask AI doesn't make changes itself. It shows each change as a card, and nothing changes until you confirm it. For example:

    - `Which applications do I have?`
    - `What permissions does the Order Manager role have?`
    - `Create a single-page application named Store Front with the redirect URL https://localhost:3000.`
    - `Create a group named Support with the users alex and sam.`
    - `Review the security of the Portal application.`
    - `Map the attributes of my HRDatabase user store: first_name VARCHAR(100), last_name VARCHAR(100), email VARCHAR(255), phone VARCHAR(20), birth_date DATE`
    - `In HRDatabase, map the Mobile claim to phone.`
