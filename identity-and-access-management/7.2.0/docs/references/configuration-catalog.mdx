The configuration model of WSO2 Identity Server is based on the toml format. The `<IS_HOME>/repository/conf/deployment.toml` file is the single source used to configure and tune various features.

This document describes all the configuration parameters used in {edition.productName}.

## Server `[server]` {#server}

Basic configurations to identify and deploy a WSO2 Identity Server node.

**Sample configuration**

```toml
[server]
hostname = "localhost"
node_ip = "127.0.0.1"
base_path = "${carbon.protocol}://${carbon.host}:${carbon.management.port}"
serverDetails = "WSO2 Identity Server"
```

| Parameter | Type | Required | Default | Possible values | Description |
|---|---|---|---|---|---|
| `hostname` | string | Yes | `localhost` | `localhost`, `127.0.0.1`, `<any-ip-address>`, `<any-hostname>` | The hostname of the machine hosting the Identity Server instance. |
| `node_ip` | string | Yes | `127.0.0.1` |  | The IP address of the machine hosting the Identity Server instance. |
| `base_path` | string | No | `${carbon.protocol}://${carbon.host}:${carbon.management.port}` |  | The base path URL used to access the server. |
| `serverDetails` | string | No | `WSO2 Identity Server` |  | A description of the server instance. |

## Shared database pool options `[database.shared_db.pool_options]` {#shared-database-pool-options}

Connection pool settings for the shared database. Tune these based on your database server capacity and load.

**Sample configuration**

```toml
[database.shared_db.pool_options]
maxActive = 80
maxWait = 360000
minIdle = 5
testOnBorrow = true
validationInterval = 30000
validationQuery = "SELECT 1"
defaultAutoCommit = false
commitOnReturn = true
```

| Parameter | Type | Required | Default | Possible values | Description |
|---|---|---|---|---|---|
| `maxActive` | integer | No | `80` |  | The maximum number of active connections in the pool. |
| `maxWait` | integer | No | `360000` |  | The maximum time (in milliseconds) to wait for a connection before throwing an error. |
| `minIdle` | integer | No | `5` |  | The minimum number of idle connections maintained in the pool. |
| `testOnBorrow` | boolean | No | `true` | `true`, `false` | Set to true to validate a connection before borrowing it from the pool. |
| `validationInterval` | integer | No | `30000` |  | The interval (in milliseconds) between successive connection validation runs. |
| `validationQuery` | string | No | `SELECT 1` |  | The SQL query used to validate connections. |
| `defaultAutoCommit` | boolean | No | `false` | `true`, `false` | Set to true to enable auto-commit on borrowed connections. |
| `commitOnReturn` | boolean | No | `true` | `true`, `false` | Set to true to commit any pending transactions when a connection returns to the pool. Required for PostgreSQL. |

## Clustering `[clustering]` {#clustering}

Configures cluster membership for high-availability deployments. Each node must specify its hostname and port for inter-node communication.

**Sample configuration**

```toml
[clustering]
membership_scheme = "wka"
domain = "wso2.carbon.domain"
local_member_host = "10.0.21.80"
local_member_port = 5701
members = []
```

| Parameter | Type | Required | Default | Possible values | Description |
|---|---|---|---|---|---|
| `membership_scheme` | string | Yes | `wka` | `wka`, `multicast`, `kubernetes`, `aws`, `aws-ecs` | The mechanism nodes use to discover each other. Use kubernetes for containerized deployments and aws-ecs for Amazon ECS. |
| `domain` | string | No | `wso2.carbon.domain` |  | The Hazelcast cluster domain name. Nodes with the same domain form a cluster. |
| `local_member_host` | string | Yes | `10.0.21.80` |  | The IP address or hostname of this node, used for cluster communication. |
| `local_member_port` | integer | Yes | `5701` |  | The port this node listens on for cluster communication. |
| `members` | array | No | `[]` |  | A list of cluster member addresses in host:port format. Used for well-known address (WKA) membership. |
